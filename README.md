# CoreSmith
CoreSmith: install/uninstall utility software with winget



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* List of ~340 apps available in [winget](https://learn.microsoft.com/windows/package-manager/winget/), grouped by category (read from `WingetDB.csv`)
* Check the apps you want; click an app to see its description
* Export / Import the checked apps to/from a JSON file
* Planned: install / uninstall the checked apps with winget
